# 🏠 MyKakeibo - UGREEN NAS Docker デプロイガイド

このドキュメントでは、家計簿アプリケーション「MyKakeibo」を **UGREEN NAS（緑聯 NAS / UGOS Pro）** の Docker 環境へデプロイする手順をわかりやすく解説します。

---

## 📋 事前準備

以下のファイル・フォルダがプロジェクト一式に含まれていることを確認してください：

```text
kakeibo01/
├── app/                  # フロントエンド（HTML/CSS/JS/マニュアル）
├── Dockerfile            # コンテナビルド定義 (Node.js 22 Alpine)
├── docker-compose.yml    # Compose定義 (ポート9090, 永続化マウント)
├── package.json          # 依存関係定義 (Express, CORS)
├── server.js             # バックエンドAPI & 静的配信サーバー
└── .dockerignore         # コンテナビルド除外設定
```

---

## 🚀 デプロイ手順

デプロイ方法は **【方法1: NAS 管理画面 (GUI)】** と **【方法2: SSH (CLI)】** の2通りあります。お好みの方法をお選びください。

---

### 【方法1】UGREEN NAS 管理画面（Docker アプリ）からデプロイする（推奨・簡単）

#### ステップ 1: NAS 上にフォルダを作成してファイルを配置
1. UGREEN NAS のデスクトップ画面から **「ファイル」**（ファイルマネージャー）を開きます。
2. `docker` 共有フォルダ配下に **`kakeibo`** という名前のフォルダを作成します（例: `/docker/kakeibo`）。
3. 作成した `kakeibo` フォルダ内に、本プロジェクトの全ファイル（`app` フォルダ、`Dockerfile`、`docker-compose.yml`、`package.json`、`server.js`、`.dockerignore`）をアップロードします。

#### ステップ 2: Docker アプリでプロジェクトを作成・起動
1. UGREEN NAS のデスクトップから **「Docker」** アプリを開きます。
2. 左メニューの **「プロジェクト」** をクリックし、**「プロジェクトを作成」**（または「追加」）をクリックします。
3. 設定項目を入力します：
   - **プロジェクト名**: `kakeibo`
   - **パス**: 先ほど作成した `/docker/kakeibo` を選択
   - **docker-compose.yml**: 自動的に読み込まれます（内容を確認）
4. **「プロジェクトをビルドして起動」**（または「作成」）をクリックします。
5. 数十秒でイメージが自動ビルドされ、コンテナが起動します。ステータスが **「実行中（Healthy / 正常）」** になれば完了です！

---

### 【方法2】SSH / ターミナルから `docker compose` でデプロイする

コマンドライン操作に慣れている方向けの手順です。

#### ステップ 1: NAS に SSH ログイン
```bash
ssh <ユーザー名>@<UGREEN_NASのIPアドレス>
```

#### ステップ 2: プロジェクトディレクトリに移動
```bash
# 例: /volume1/docker/kakeibo に配置した場合
cd /volume1/docker/kakeibo
```

#### ステップ 3: コンテナのビルドと起動
```bash
docker compose up -d --build
```

#### ステップ 4: 稼働状態の確認
```bash
# コンテナの状態を確認
docker compose ps

# ログを確認
docker compose logs -f
```

## 🌐 アプリケーションへのアクセス

コンテナ起動後、PC やスマートフォンのブラウザから以下の URL にアクセスします：

- **メイン画面（ダッシュボード・収支・口座管理）**:
  ```text
  http://<UGREEN_NASのIPアドレス>:9090
  ```
- **スマホ専用伝票入力画面**:
  ```text
  http://<UGREEN_NASのIPアドレス>:9090/mobile-input.html
  ```

> [!TIP]
> ポート番号を変更したい場合は、`docker-compose.yml` 内の `ports:` 部分（`"9090:80"`）の左側の数値を自由に変更してください（例: `"8088:80"`）。

---

## 📱 スマートフォンでの快適な使い方（ホーム画面に追加）

「スマホ専用伝票入力画面」は PWA に対応しており、スマホのホーム画面にアイコンを追加することで、ネイティブアプリのようにワンタップで素早く起動・入力できます。

1. スマホのブラウザ（iPhone は Safari、Android は Chrome）で `http://<NASのIP>:9090/mobile-input.html` を開く。
2. **共有ボタン**（またはメニューボタン）をタップ。
3. **「ホーム画面に追加」** を選択。
4. ホーム画面に「伝票入力」アイコンが追加され、いつでもテンキーで支出・収入をサクサク入力できます。

## 💾 データの永続化とバックアップ

### 1. SQLite データベースの自動永続化
データは NAS 側のフォルダ（`./data/kakeibo.db`）に自動保存されます。
コンテナを停止・再作成・更新してもデータが消えることはありません。

### 2. ワンクリック JSON バックアップ
ブラウザから以下の URL を開くだけで、全取引・予算・口座データの最新バックアップ（JSON ファイル）が即座にダウンロードされます：
```text
http://<UGREEN_NASのIPアドレス>:9090/api/export
```

### 3. NAS 全体バックアップ
NAS の「ファイル」アプリから `/docker/kakeibo/data` フォルダを別のドライブやクラウド（UGREEN クラウドバックアップ等）に定期コピーするだけで、完全なデータベースバックアップが完了します。

## 🔄 アプリケーションの更新・停止・再起動

### アプリを停止する
- **GUI**: Docker アプリの「プロジェクト」一覧から `kakeibo` を選択し「停止」。
- **CLI**:
  ```bash
  docker compose down
  ```

### アプリを更新・再起動する
ソースコードを修正した場合は、以下のコマンドで再ビルド・再起動できます：
```bash
docker compose up -d --build
```
